
Datatypes- A datatype defines the kind of value a variable and what operations can performed.

Python decides the type automatically from the value,so we never declare it.

There are 8 categories with 14 datatypes:

category           |       Types        |

1.Text  Datatype     ----->str

2.Numeric Datatypes   ---->int,float,complex

3.sequence Datatypes -->List,tuple,range

4.Mapping Datatypes   --->dict

5.Set Datatypes      --->set,frozenset

6.Boolean Datatype   --->bool

7.Binary Datatypes  --->bytes,bytearray,memoryview

8.None Datatype   ----->none


#Type      |   Description     | Example      | Mutable(when we modify it goes to new memory)

int     |  Whole numbers   |age =10           | yes
float|  |  Decimal values  | weight =55.6     |yes
bool    | true or false    | is_girl = True   |yes
complex | real + imaginary | a = 2+4j         |yes
str     |  Text            | a="Harshi"       |yes
NoneType |represents no value |result='None'  |yes
